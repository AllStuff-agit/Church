# 예배 PPT 조립 도구 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 구조 템플릿(txt) × 테마 템플릿(pptx) × 그 주 내용(json)으로 16:9 주일 예배 PPT를 만드는 도구와, 첫 테마·구조 템플릿을 만든다.

**Architecture:** 테마 pptx를 복사한 뒤, 구조 순서대로 테마의 종류별 견본 슬라이드를 같은 파일 안에서 복제·채우고, 견본 원본은 지우고, 섹션을 다시 만든다. 찬송·준비찬양은 기존 `replace_section_zip`으로 해당 섹션에 끼운다. 내용은 `1_자료`의 txt에서 읽는다.

**Tech Stack:** Python 3.13(`python -X utf8`), python-pptx 1.0.2, lxml, 표준 `unittest`, LibreOffice(`.ppt` 변환·렌더링).

**Spec:** `docs/superpowers/specs/2026-11-01-예배PPT-템플릿-구조-설계.md`

## Global Constraints

- 원본 경로: 교독문 `1_자료/교독문/교독문_N.txt`, 성경 `1_자료/개역개정성경/구약|신약/NN_책/책NN장.txt`(시편은 `시편NN편.txt`).
- 찬송 `1_자료/찬송가/새찬송가_NNN장.ppt`(번호 세 자리), 찬양곡 `1_자료/찬양곡/`.
- 테마 `2_템플릿/테마/테마-<특색>.pptx`, 구조 `2_템플릿/구조/구조-주일기본.txt`, 결과 `4_예배PPT/주일/YYMMDD_주일.pptx`.
- 테마의 9종 슬라이드 종류 이름(섹션 이름과 같음): `대기`, `사도신경`, `교독문`, `참회기도`, `본문표지`, `말씀구절`, `소식`, `축도`, `엔딩`.
- 끼우는 항목: `준비찬양`, `찬송`(번호 있으면 고정, 예: `찬송 635`).
- 상자 이름: 교독문 `교독문제목`·`교독문본문`, 본문표지 `성경구절`·`설교제목`(글자 배치형은 묶음 `본문 타이틀`), 말씀구절 `구절본문`·`구절장`.
- 교독문: 한 장 4~6줄, 인도/회중 색 구분(견본 두 색), `인도:`·`회중:` 글자 없음, 다같이 줄 앞 `(다같이)`, 쌍이 장을 넘어 끊기지 않음, 매 장 `교독문 N. 제목`.
- 말씀구절: 한 장 한 절, 앞에 절 번호, 긴 절은 두 장(두 번째 장 절 번호 없음, 단어 중간 자르지 않음), `<…>` 소제목 제외, `구절장`에 `민수기 31장`.
- 본문표지 제목 표기: 조사 약 77%·조금 아래, `(괄호)` 작게 내림, `[대괄호]` 약 95%, 따옴표 사이 폭 넘으면 비율 축소 후 낱말 경계 두 줄.
- 오류는 무엇이 없는지 한국어로 알리고 멈춘다(예: `이 테마에는 교독문 슬라이드가 없습니다`).
- 모듈은 `도구/worship_ppt`를 `sys.path`에 넣고 `import sources`처럼 최상위로 불러온다(테스트 파일 맨 위에서 `sys.path.insert(0, str(Path(__file__).parents[1]))`, `assemble.py`도 같은 방식).
- 커밋 메시지는 저장소 규칙(AGENTS.md): 날짜 없는 공통 작업은 한국어 설명형, Conventional Commits 접두어 금지.

- **주 사용자는 Claude다.** 매주 Claude가 명령줄로 실행하고 결과를 직접 확인한다. 그래서 출력은 사람이 아니라 Claude가 읽기 쉽게: 오류는 파일·항목·값을 구체적으로, 성공 시 섹션별 장 수 요약을 출력한다. `render`(PNG 미리보기)와 `verify`(txt 대조)를 도구에 포함한다.

## Review Focus

- 장을 넘는 본문(`사무엘하 21:1-22:3`)과 여러 구간(`마태 4:8-10, 요한 12:12-15`): 구간 순서대로 이어져야 함 → Task 1 테스트.
- 책 이름 변형(`삼하`, `사무엘하`, `요한1서`/`요한일서`, `시편`의 `편`): 모두 같은 책으로 찾아야 함 → Task 1 테스트.
- 한 장에 안 들어가는 아주 긴 교독문 한 줄: 장을 나누되 내용이 빠지면 안 됨 → Task 5 테스트.
- 조사가 없거나 아주 긴 설교 제목: 따옴표 사이를 넘지 않음 → Task 7 테스트.
- 없는 찬송 번호·찬양곡 파일: 조립 전에 알리고 멈춤 → Task 8 테스트.

```python
def test_gyodokmun_9(self):
    g = load_gyodokmun(9)
    self.assertEqual(g.title, "시편 15편")
    self.assertEqual(g.lines[0], ("인도", "여호와여 주의 장막에 머무를 자 누구오며"))
    self.assertEqual(g.lines[-1][0], "회중")
    self.assertTrue(g.lines[-1][1].endswith("(1-5) (아멘)"))

def test_reference_variants(self):
    self.assertEqual(parse_reference("삼하 21:1-14"), [Passage("사무엘하", 21, 1, 14)])
    self.assertEqual(parse_reference("사무엘하 21:1~14"), [Passage("사무엘하", 21, 1, 14)])
    self.assertEqual(parse_reference("요한1서 4:7")[0].book, "요한일서")
    self.assertEqual(parse_reference("시 23:1-6")[0].book, "시편")

def test_reference_multi(self):
    self.assertEqual(parse_reference("마태 4:8-10, 요한 12:12-15"),
                     [Passage("마태복음", 4, 8, 10), Passage("요한복음", 12, 12, 15)])
    self.assertEqual(parse_reference("사무엘하 21:1-22:3"),
                     [Passage("사무엘하", 21, 1, 22), Passage("사무엘하", 22, 1, 3)])

def test_verses_strip_heading(self):
    vs = load_verses(Passage("창세기", 1, 1, 2))
    self.assertEqual(vs[0], (1, "태초에 하나님이 천지를 창조하시니라"))
    self.assertEqual(len(vs), 2)

def test_display(self):
    self.assertEqual(display_reference([Passage("민수기", 31, 1, 6)]), "민수기 31장 1-6절")
    self.assertEqual(display_reference([Passage("시편", 23, 1, 6)]), "시편 23편 1-6절")

def test_missing(self):
    with self.assertRaisesRegex(SourceError, "교독문 999"):
        load_gyodokmun(999)
    with self.assertRaisesRegex(SourceError, "민수기 31장 60절"):
        load_verses(Passage("민수기", 31, 60, 60))
```
