# 예배 테마·구조 템플릿 만들기 (16:9)

저장소 루트는 `C:/Oddments_Repository/교회`, 명령은 루트에서 Windows `python -X utf8`로 실행한다. 매주 PPT 만들기는 `worship-ppt` 스킬이 하고, 이 스킬은 거기에 쓸 템플릿만 만든다.

| 항목 | 경로 |
|---|---|
| 테마 템플릿 | `2_템플릿/테마/테마-이름.pptx` (예: `테마-성탄.pptx`) |
| 구조 템플릿 | `2_템플릿/구조/구조-이름.txt` (예: `구조-성탄.txt`) |
| 기준 테마 | `2_템플릿/테마/테마-초록잎들꽃.pptx` |
| 시험 내용 | 이 스킬 폴더의 [시험내용.json](시험내용.json) |
| 임시 폴더 | `로컬전용/작업/템플릿/` (git에 안 올라감, 끝나면 지움) |

## 테마 규칙

조립 도구는 섹션 이름과 상자 이름으로 슬라이드를 찾는다. 디자인은 자유지만 아래는 지켜야 한다.

- **16:9**, 슬라이드 크기는 33.867×19.05cm(12192000×6858000)를 권한다. 찬양곡·찬송가는 끼울 때 이 크기에 맞게 키워진다.
- 9종 슬라이드를 **같은 이름의 섹션**에 둔다: `대기`, `사도신경`, `교독문`, `참회기도`, `본문표지`, `말씀구절`, `소식`, `축도`, `엔딩`. 구조에 안 쓰는 종류는 없어도 된다.
- 상자 이름(PowerPoint 홈 → 정렬 → 선택 창, Alt+F10에서 바꿈):

| 섹션 | 상자 | 내용 |
|---|---|---|
| 교독문 | `교독문번호`, `교독문부제` (표지 장, 선택) | `교독문 N번`, 교독문 제목 |
| 교독문 | `교독문제목`, `교독문본문` (본문 장, 필수) | 제목, 인도/회중 줄 |
| 본문표지 | `성경구절` (필수) | `사무엘하 21:1-14` |
| 본문표지 | `설교제목` 상자 **또는** `본문 타이틀` 묶음 | 설교 제목 |
| 말씀구절 | `구절본문`, `구절장` (필수) | 절 번호+본문, `사무엘하 21장` |

- `교독문본문`에는 견본 문단 **4개**를 순서대로 둔다: ① 인도 줄 ② 회중 줄 ③ `(다같이)` 표시 ④ 다같이 본문(마지막 조각은 `(아멘)` 등 꼬리 글자 서식). 도구는 이 서식을 복사해 쓴다. 교독문 글꼴은 PPT 기본 글꼴(맑은 고딕, 바탕 등)만 쓴다.
- 각 상자의 첫 단락 첫 글자 조각의 서식이 그대로 쓰인다. 견본 글자는 아무 내용이어도 된다.
- `본문 타이틀` 묶음(글자 배치형 제목)은 `설교제목글자*` 글자 상자와 `따옴표` 묶음(`따옴표-left`, `따옴표-right`)을 쓰고, 글자 위치 기준값은 `도구/worship_ppt/title.py`의 `BASE`(초록잎들꽃 측정값)다. 새 테마에서 글자 상자 크기·위치가 다르면 단순형 `설교제목` 상자를 권한다.

## A. 사용자가 디자인한 테마 맞추기 (보통)

1. 파일을 받아 `2_템플릿/테마/테마-이름.pptx`로 복사한다(원본은 건드리지 않는다). 이름은 사용자에게 확인한다.
2. 점검:
   ```bash
   python -X utf8 도구/worship_ppt/assemble.py check-theme 2_템플릿/테마/테마-이름.pptx [--구조 2_템플릿/구조/구조-이름.txt]
   ```
   섹션별 장 수와 고칠 곳이 나온다. 종료 코드 1이면 고칠 곳이 있다.
3. 고칠 곳은 python-pptx로 고친다. 섹션 이름은 `slides.set_sections`, 상자 이름은 `shape.name = "구절본문"`. **어느 상자가 무엇인지 애매하면 추측하지 말고** 그림으로 보여 주며 묻는다. 디자인(색·글꼴·위치)은 사용자 요청 없이 바꾸지 않는다.
4. 다시 `check-theme`이 통과할 때까지 반복한 뒤 **시험 조립**(아래)으로 확인한다.

## B. 배경 그림으로 새 테마 만들기 (시험용)

1. 기준 테마(`테마-초록잎들꽃.pptx`)를 `테마-이름.pptx`로 복사한다. 섹션·상자 이름은 그대로 살아 있다.
2. 각 슬라이드의 배경과 장식 그림을 받은 그림으로 바꾼다. 장식이 새 배경과 어울리지 않으면 지운다. 상자는 지우지 않는다.
3. 글자가 배경 위에서 잘 읽히게 색을 맞춘다(밝은 배경엔 어두운 글자, 어두운 배경엔 밝은 글자와 그림자). 교독문 인도/회중/(다같이) 세 줄은 서로 구분되게 유지한다.
4. `check-theme` → 시험 조립 → 그림을 사용자에게 보여 주고 고칠 점을 묻는다. 사용자가 좋다고 하면 정식 테마로 쓴다.

## C. 구조 만들기

구조는 예배 순서를 한 줄에 하나씩 적은 UTF-8 txt다. 쓸 수 있는 항목:

- 테마 슬라이드: `대기`, `사도신경`, `교독문`, `참회기도`, `본문표지`, `말씀구절`, `소식`, `축도`, `엔딩`
- 끼우기: `준비찬양`(그 주 곡 수만큼 `준비찬양 1`, `준비찬양 2`… 섹션이 생김), `찬송`(번호 없으면 그 주 내용의 `찬송`에서 차례로), `찬송 635`(번호 고정)

같은 항목이 여러 번 나오면 섹션이 `대기 1`, `대기 2`처럼 번호가 붙는다. 기준: [2_템플릿/구조/구조-주일기본.txt](../../../2_템플릿/구조/구조-주일기본.txt).

1. 주보나 사용자 설명에서 순서를 읽어 `구조-이름.txt`를 쓴다. 위 목록에 없는 순서(예: 성찬, 특송)는 지금 도구로 만들 수 없으므로 빼지 말고 사용자에게 알려 어떻게 할지 정한다(가까운 슬라이드로 대신, 또는 도구에 종류 추가).
2. 쓸 테마로 `check-theme --구조`를 돌리고 시험 조립한다.

## 시험 조립

```bash
python -X utf8 도구/worship_ppt/assemble.py build --구조 2_템플릿/구조/구조-주일기본.txt --테마 2_템플릿/테마/테마-이름.pptx \
  --내용 .claude/skills/worship-template/시험내용.json --출력 로컬전용/작업/템플릿/시험.pptx
python -X utf8 도구/worship_ppt/assemble.py render 로컬전용/작업/템플릿/시험.pptx --폴더 로컬전용/작업/템플릿/png
```
`sheet.png`와 각 장 그림을 Read 도구로 보고 확인한다: 교독문 글자 넘침과 인도/회중/(다같이) 구분, 본문표지 제목 배치, 말씀구절 절 나눔, 찬송·준비찬양이 화면을 채우는지, 배경 위 글자 가독성. 대표 장 그림을 사용자에게 보낸다.

## 마무리

- `로컬전용/작업/템플릿/`을 지운다(삭제 전 경로 확인). 사용자가 준 원본 파일은 지우지 않는다.
- 보고: 만든 파일 경로, 고친 내용(섹션·상자 이름), 확인한 그림, 판단이 필요했던 부분.
- 커밋은 사용자가 요청할 때만. 메시지는 날짜 없는 한국어 설명형(예: `성탄절 테마 템플릿 추가`, `성탄절 예배 구조 추가`).
