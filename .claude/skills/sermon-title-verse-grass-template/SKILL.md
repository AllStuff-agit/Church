# Sermon Title Verse Grass Template

## 목적

예배 PPT의 기존 `설교` 섹션만 교체한다. 다른 예배 순서 섹션은 건드리지 않는다.

최종 설교 섹션 구조는 항상 다음과 같다.

```text
[본문 + 설교 제목 슬라이드]
[본문 1절 슬라이드]
[본문 2절 슬라이드]
...
[본문 마지막 절 슬라이드]
[본문 + 설교 제목 슬라이드]
```

## prompt.txt와 전체 예배 PPT 연계

- 전체 예배 PPT 작업에서는 `church-worship-ppt`가 조립을 마친 뒤 Skill 도구로 이 스킬을 호출한다. 이 스킬이 `prompt.txt` 형식 입력(주보·준비찬양 경로)과 함께 직접 호출되면 전체 예배 준비 요청으로 보고 `church-worship-ppt`부터 진행한다. 날짜 치환과 HWP/HWPX의 PDF 판독은 `../church-worship-ppt/SKILL.md`의 Step 1~2를 따른다. 오늘이 일요일이면 다음 주 일요일을 사용하며, 두 스킬은 같은 예배 날짜와 대상 PPT를 공유한다.
- `church-worship-ppt`가 조립한 대상 파일에 주보에서 읽은 설교 제목·본문을 적용한다. 설교 작업을 위해 대상 PPT를 템플릿으로 다시 초기화하거나 준비찬양을 덮어쓰지 않는다.
- 전체 작업에서는 두 스킬의 실행과 최종 화면 검증을 모두 마친 뒤 임시 파일을 정리한다. `prompt.txt`, 스킬, 원본 자료와 최종 PPT는 보존한다.

## 실행 환경 (Claude Code on Windows)

- python-pptx·LibreOffice·pdftoppm은 WSL에만 있으므로 스크립트와 렌더링 명령은 `wsl -e`로 실행하고 인자 경로는 `/mnt/c/...`로 넘긴다.
- Bash 도구(Git Bash)에서는 앞에 `MSYS_NO_PATHCONV=1`을 붙인다. 없으면 `/home/...` 경로가 Git 설치 경로로 바뀌어 실패한다. PowerShell 도구에서는 붙이지 않는다.
- 섹션 교체 헬퍼는 같은 skills 폴더의 `church-worship-ppt/scripts/ppt_section_replacer.py`를 자동으로 찾는다(`--section-replacer`로 바꿀 수 있음).
- 렌더링한 화면은 Read 도구로 직접 확인한다.
- 임시 폴더는 `C:/Oddments_Repository/교회/gitignore/workspace/.build/YYMMDD/`(WSL: `/mnt/c/Oddments_Repository/교회/gitignore/workspace/.build/YYMMDD/`)를 쓴다. `/tmp`는 쓰지 않는다.

## 사용 절차

1. 주보에서 설교 본문과 제목을 확인한다.
   - 예: 본문 `사사기 4:1-10`, `사도행전 2:1-4,14-18`, `마태복음 16:18/에베소서 2:20-22`, `마태 4:8-10, 요한 12:12-15`
   - 예: 제목 `절망의 밤에 세우신 사람 드보라`
2. 대상 예배 PPTX의 `설교` 섹션이 있는지 확인한다.
3. 아래 스크립트로 `설교` 섹션만 교체한다.

```bash
MSYS_NO_PATHCONV=1 wsl -e /home/wl/venvs/mybase/bin/python3 \
  "/mnt/c/Oddments_Repository/교회/.claude/skills/sermon-title-verse-grass-template/scripts/sermon_grass_replacer.py" \
  --target "/mnt/c/Oddments_Repository/교회/주일 예배자료/1. 주일오전예배ppt/260615월.pptx" \
  --reference "사사기 4:1-10" \
  --title "절망의 밤에 세우신 사람 드보라"
```

## 스크립트 동작 원칙

- `설교` 섹션의 기존 첫 슬라이드를 제목 템플릿으로 사용한다.
- `설교` 섹션의 기존 두 번째 슬라이드를 본문 구절 템플릿으로 사용한다.
- `설교` 섹션의 기존 마지막 슬라이드를 마지막 제목 템플릿으로 사용한다.
- 제목 슬라이드의 본문 표기는 `사사기 4장 1-10절` 같은 형식으로 바꾼다. 여러 책 본문은 `/`가 아니라 `마태복음 16장 18절, 에베소서 2장 20-22절`처럼 쉼표로 구분하고, 한 줄로 보이게 한다.
- 텍스트 글꼴/색/굵기/정렬은 기존 설교 섹션 템플릿의 텍스트박스 서식을 기본값으로 보존하고, 텍스트 내용만 바꾼다.
- 설교 제목은 기존 제목 글자 텍스트박스를 복제해 글자 하나하나를 개별 텍스트박스로 만든 뒤 중앙에 보기 좋게 배치한다. 핵심 단어의 글자는 더 크게, 조사/어미/문장부호는 조금 작게 하고, 글자 크기에 맞춰 위아래 위치도 미세 조정한다.
- 설교 제목 줄바꿈은 임의의 단어 중간에서 만들지 않는다. 제목에 사용자가 명시한 줄바꿈이 있으면 그대로 우선하고, 없으면 쉼표·콜론·세미콜론 같은 문장 경계를 우선하여 의미 단위로 나눈다. 예를 들어 `120년의 은혜, 다시 성령의 부흥으로`는 `120년의 은혜,` 다음에 줄바꿈하여 `다시 성령의 부흥으로`를 배치한다.
- 설교 제목 글자들은 `본문 타이틀` 그룹 안에 생성한다. 본문+설교 제목 슬라이드의 애니메이션은 스크립트가 임의 생성하지 말고, 기본 `template.pptx`의 `설교` 섹션 첫/마지막 제목 슬라이드에 사용자가 PowerPoint에서 직접 적용해 둔 효과를 그대로 복사한다. 복사 시 새 슬라이드에서 바뀐 도형 ID는 `그룹 49`, `성경구절`, `본문 타이틀` 같은 도형 이름을 기준으로 다시 연결한다. 애니메이션 템플릿이나 대상 도형 연결에 문제가 있으면 임의 효과를 만들지 말고 오류로 중단한다.
- 같은 PPT에 스킬을 여러 번 다시 적용해도 제목 크기가 누적해서 커지지 않도록, 제목 배치의 기준 글자 크기는 안정적인 디자인 기준값으로 제한한다.
- 본문 구절은 성경 PPT 루트에서 해당 책/장 파일을 찾아 추출한다. 쉼표로 나뉜 불연속 범위, `/` 또는 `;`로 나뉜 여러 책 본문, 그리고 `마태 4:8-10, 요한 12:12-15`처럼 쉼표 뒤 새 책 이름이 오는 여러 책 본문도 지원한다.
- 본문 슬라이드는 한 슬라이드에 한 절씩 생성한다.
- 본문 슬라이드 왼쪽 상단 헤더는 `TextBox 1`로 정리하고, 기존 템플릿의 `TextBox 8`도 호환 입력으로 읽은 뒤 `TextBox 1`로 이름을 바꾼다.
- 본문 슬라이드 왼쪽 상단의 장 표기(`데살로니가전서 5장` 등)는 반드시 한 줄로 유지한다. 텍스트 상자의 자동 줄바꿈을 끄고, 긴 책 이름은 텍스트 상자 폭을 안전 영역 안에서 넓힌 뒤 필요한 경우 글자 크기를 조금 줄인다. 책 이름과 장 번호를 두 줄로 만들지 않는다.
- 본문 슬라이드의 본문 영역은 `TextBox 2`로 정리하고, 기존 템플릿의 `TextBox 15`도 호환 입력으로 읽은 뒤 `TextBox 2`로 이름을 바꾼다.
- 본문 슬라이드의 미사용 `TextBox 22`는 생성 결과에서 제거한다.
- 본문 텍스트는 자동 번호 매김을 사용하지 않고, 절 번호도 `1  본문...`처럼 숫자 뒤에 공백 두 칸을 둔 일반 텍스트로 넣는다. 본문 슬라이드의 본문 영역(`TextBox 2`) 글자 크기는 기본 32pt로 한다. 다만 긴 절이 텍스트박스 높이를 거의 다 채워 아래 여백이 부족해질 때는, 템플릿의 실제 줄간격을 반영하여 텍스트박스의 시각적 안전 영역(대략 상단 80%) 안에 들어가도록 0.5pt 단위로 살짝 줄여 하단 여백을 남긴다.
- 본문 영역(`TextBox 2`)은 PowerPoint 자동 줄바꿈에 맡기지 않고, 단어가 중간에 분리되지 않도록 단어 단위로 직접 줄내림을 넣는다. 자동 번호 매김의 남은 들여쓰기/내어쓰기 설정은 제거해서 절 번호와 본문이 기존 텍스트박스 가로폭 밖으로 나가지 않게 한다.
- 교체 후 LibreOffice로 PPTX를 정규화하고 `p14:sectionLst` 구역 정보를 복원한다.

python - <<'PY'  # Windows python(anaconda)에도 python-pptx가 있다

prs = Presentation(p)
print(len(prs.slides), prs.slide_width, prs.slide_height)

## 작업 완료 후 정리 (필수)

- 최종 PPT는 지정된 예배 PPT 저장 폴더(`C:/Oddments_Repository/교회/주일 예배자료/1. 주일오전예배ppt/`, WSL: `/mnt/c/Oddments_Repository/교회/주일 예배자료/1. 주일오전예배ppt/`)에 저장한다. 사용자가 별도 최종 경로를 지정하면 그 경로를 따른다.
- 임시 산출물은 작업별 임시 폴더에 모으고 생성 경로를 기록한다. 변환 PPTX, 후렴 추출본, PDF, 검사용 이미지, 임시 실행 스크립트, 작업 사본, 백업은 최종 산출물이 아니다.
- 최종 파일의 저장과 무결성·내용·화면 검증을 마친 뒤, 이번 작업에서 만든 임시 파일·작업 사본·백업을 모두 삭제한다. 백업도 남기지 않는다. 작업 사본을 최종 경로로 복사했다면 두 파일의 해시가 같은지 확인한 후 사본을 삭제한다.
- `prompt.txt`, 스킬 폴더와 그 안의 지침·스크립트·리소스, 원본 템플릿, 주보·준비찬양 HWP·성경·찬양 자료, 지정 경로의 최종 PPT는 정리 대상으로 삼지 않는다. 기존의 다른 작업 파일도 임의로 삭제하지 않는다.
- 재귀 삭제 전 실제 절대 경로가 해당 작업의 임시 폴더 내부인지 확인하고, 심볼릭 링크나 정션을 따라가지 않는다. 작업 폴더 전체를 일괄 삭제하지 않으며, `.build`도 다른 작업 파일이 섞여 있으면 이번 작업에서 생성한 항목만 삭제한다.
- 전체 예배 PPT 조립과 설교 교체를 연속 수행할 때는 모든 단계와 최종 검증이 끝난 뒤 정리한다. 설교 스킬만 실행해도 같은 정리 규칙을 적용하며, `--keep-temp`로 남긴 폴더도 검증 후 삭제한다. 실패·중단 상태에서 유일한 결과물이나 복구에 필요한 파일을 먼저 삭제하지 않는다.
- 완료 보고 전에 임시 파일·작업 사본·백업이 남지 않았고, 최종 파일과 보존 대상이 유지되었는지 확인한다.

## 주의

- 이 스킬은 새 예배 PPT 전체를 만들지 않는다. 전체 PPT 생성은 `church-worship-ppt`를 사용한다.
- 원본 템플릿은 수정하지 않는다.
- 대상 PPTX를 직접 수정하므로, 사용자가 새 파일 생성을 원하면 먼저 별도 복사본을 만든 뒤 실행한다.
- 성경 본문은 개역개정성경 PPT 파일에서 추출한 텍스트를 사용한다.
