# 교회 예배 PPT 조립 스킬

## 개요

매주 예배 PPT를 만들 때, 주보에 나온 예배순서를 보고 자료 폴더에서 알맞은 슬라이드를 찾아 메인 템플릿에 조립해주는 스킬이다.

**핵심 흐름:**
주보(예배순서) → 자료 스캔 → 매칭 → PPT 조립 → 새 파일 저장

준비찬양이 있는 경우 HWP 파일도 함께 받는다:
준비찬양 HWP → 이미지 추출 → 곡 제목 확인(없으면 웹 검색) → 찬양곡 폴더 탐색 → 준비찬양 1~4 섹션 교체

## Step 1 – 파일 준비

템플릿을 복사해서 오늘 날짜로 저장한다:

```bash
# 오늘 날짜로 자동 생성
python3 ~/.claude/skills/church-worship-ppt/scripts/ppt_section_replacer.py --init

# 날짜 직접 지정 시 (예: 다음 주 준비)
python3 ~/.claude/skills/church-worship-ppt/scripts/ppt_section_replacer.py --init --date 260405
```

파일명 날짜 형식: `YYMMDD` (예: 오늘이 2026년 3월 29일이면 `260329주일.pptx`)

이후 이 복사본을 작업 대상으로 사용한다. 템플릿 원본(`template.pptx`)은 절대 수정하지 않는다.

## Step 2 – 입력 수집

- **주보**: 사용자가 이미지 경로를 직접 알려준다 (JPG/PNG) 또는 텍스트 직접 입력 — 필수
- **준비찬양 파일**: 고정 경로에서 날짜로 자동 탐색

```
준비찬양 고정 경로: /mnt/c/Oddments_Repository/교회/주일 예배자료/6. 준비찬양/
파일명 패턴: YYMMDD*.hwp 또는 YYMMDD*.hwpx  (예: 260405오전.hwpx)
```

날짜를 알면 아래 명령어로 자동 탐색 및 추출:
```bash
# 오늘 날짜로 자동 탐색
python3 ppt_section_replacer.py --extract-hwp

# 날짜 지정
python3 ppt_section_replacer.py --extract-hwp --date 260405
```

준비찬양 파일이 없는 주는 해당 단계를 건너뛴다.

## Step 3 – 주보에서 예배순서 파악

### 이미지 주보인 경우
이미지를 직접 읽어서 예배순서 항목을 추출한다. 예:
- "경배와 찬양 – 찬송 10장, 25장"
- "대표기도"
- "성경봉독 – 마태복음 5:1-12"
- "설교 – 제목: 팔복"
- "헌금"
- "광고 및 폐회"

### 텍스트 입력인 경우
사용자가 입력한 텍스트를 파싱해서 같은 형태로 구조화한다.

**결과 구조 예시:**
```json
[
  {"순서": 1, "항목": "경배와 찬양", "상세": ["찬송 10장", "찬송 25장"]},
  {"순서": 2, "항목": "대표기도", "상세": []},
  {"순서": 3, "항목": "설교", "상세": ["마태복음 5:1-12", "팔복"]},
  {"순서": 4, "항목": "헌금", "상세": []}
]
```

## Step 4 – 자료 파일 매칭

주보에서 추출한 항목을 아래 규칙으로 자료 파일과 매칭한다.

### 준비찬양 (HWP 파일이 있는 경우)

#### Step A — 준비찬양 순서 확정

준비찬양 섹션 순서는 아래 우선순위로 확정한다. **절대 HWP 이미지 추출 파일명/추출 순서만으로 준비찬양 1~4를 확정하지 않는다.**

1. 사용자가 준비찬양 목록이나 순서를 직접 준 경우 → **사용자 순서를 최우선으로 그대로 사용**
2. 주보/준비찬양 문서에 번호 또는 명확한 배치 순서가 보이는 경우 → 그 순서를 사용
3. `--extract-hwp` 결과에 `page` / `col` 정보가 있는 HWPX만 아래 규칙으로 섹션 그룹을 결정
4. `layout=unknown`인 HWP 결과는 BinData 내부 저장 순서일 뿐 예배 순서가 아니다. 이 경우 이미지를 직접 보아도 순서를 확정할 수 없으면 사용자에게 확인을 요청한다.

`--extract-hwp` 결과의 `page` / `col` 정보가 **있는 경우에만** 섹션 그룹을 결정한다:

```
(page=1, col=왼쪽)  → 준비찬양 1
(page=1, col=오른쪽) → 준비찬양 2
(page=2, col=왼쪽)  → 준비찬양 3
(page=2, col=오른쪽) → 준비찬양 4
...
```

**같은 (page, col) 이미지가 여러 개** → 같은 섹션에 소스 파일을 순서대로 나열
**다른 (page, col)** → 별도 섹션

주의:
- HWP(OLE) 추출 결과처럼 `layout=unknown`이면 `01_...`, `02_...` 순서가 실제 예배 순서와 다를 수 있다.
- `layout=unknown` 상태에서 추출 이미지 순서를 준비찬양 1~4로 자동 배정하는 것은 금지한다.
- 순서가 불명확하면 PPT를 만들기 전에 준비찬양 순서를 짧게 확인한다.

#### Step B — 곡 제목 파악

각 이미지를 직접 읽어서 곡 제목을 확인한다:
- 악보에 제목이 명시된 경우 → 해당 제목 사용
- 제목 없이 가사만 있는 경우 → 가사 첫 줄로 웹 검색해서 곡 제목 확인
- **반드시 이미지를 직접 읽고 확인할 것. 추측 금지.**

**파일 탐색**: 준비찬양은 **항상 찬양곡 폴더**에서만 탐색한다.
- 찬송가 번호(예: 160장)여도 **찬송가 폴더를 절대 사용하지 않는다**
- 찬양곡 폴더에 없으면 → 티스토리에서 다운로드 (찬송가 폴더 fallback 금지)

탐색 순서는 찬양 1/2와 동일한 1~3단계 방식을 따른다 (아래 참조).

#### Step C — 같은 컬럼에 같은 곡이 여러 이미지로 나뉜 경우

같은 컬럼 안에 **같은 곡**의 이미지가 2개 이상인 케이스가 있다:

- **케이스 1: 악보가 2장에 걸친 경우** (1절+2절, 3절+코러스 등)
  → 해당 곡 PPT 파일을 `--source`로 **한 번만** 지정한다. 파일 안에 이미 전체 슬라이드가 포함되어 있다.

- **케이스 2: 코러스 악보(일부) + 전체 악보** (예: img3=코러스만, img4=전체 곡)
  → PPT 슬라이드를 직접 확인해서 어느 슬라이드가 코러스에 해당하는지 파악한다.
  → 확인 방법: pptx 내부 이미지 추출 후 시각적으로 판단
  ```python
  import zipfile, os
  with zipfile.ZipFile("선포하라.pptx") as z:
      for name in z.namelist():
          if name.startswith("ppt/media/"):
              with open(f"/tmp/{os.path.basename(name)}", "wb") as f:
                  f.write(z.read(name))
  ```
  → 코러스 슬라이드가 어느 번호인지 파악한 뒤 AI가 직접 판단해서 소스 구성
  → 판단이 어려우면 사용자에게 확인 요청

### 교독문
- 주보에서 번호 추출 (예: "129번" → `129`)
- 파일명: `교독문_{번호}.ppt` → `교독문_129.ppt`

### 찬양 1 / 찬양 2
- **숫자 + "장"** 형식이면 → 찬송가 폴더
  - 예: "150장" → `새찬송가_150장.ppt`
- **곡 제목** 형식이면 → 아래 순서로 탐색:

**1단계. 폴더에서 먼저 탐색**
```bash
python3 ~/.claude/skills/church-worship-ppt/scripts/ppt_section_replacer.py \
  --search --title "곡제목"
```
- 공백/특수문자 무시, 부분 일치도 탐색
- `BEST_MATCH: /경로/파일.ppt` 출력 시 → 해당 파일 사용
- 후보가 여러 개면 사용자에게 선택 요청
- exit code 2 (파일 없음) → 2단계로

**2단계. 없으면 스크립트로 티스토리에서 자동 다운로드**

```bash
python3 ~/.claude/skills/church-worship-ppt/scripts/ppt_section_replacer.py \
  --download --title "곡제목"
```

- `--title`에는 **반드시 곡 제목(가사/노래 이름)**을 사용한다. 찬송가 번호(예: "새찬송가 160장")로 검색하면 안 된다 → 곡 제목(예: "무덤에 머물러")으로 검색할 것
- 자동으로 `cwy0675.tistory.com/search/{곡제목}` 사이트 내부 검색 → 곡 제목이 앞에 오는 직접 포스트 선택 → 보호글일 때만 비밀번호(0675) 처리 → 일반 `.ppt/.pptx` 첨부 다운로드
- 첨부 목록에 `.nwc`, 일반 `.PPT`, `_Wide.PPT`가 함께 있으면 `.nwc`와 `_Wide`를 제외하고 일반 `.PPT`를 선택한다.
- 첨부 순서 `.nwc` / `.ppt` / `_Wide.ppt` 중 Wide 아닌 `.ppt` 자동 선택
- `DOWNLOADED: /경로/파일.ppt` + `BEST_MATCH: /경로/파일.ppt` 출력
- exit code 2 = 티스토리에도 없음 → 3단계로
- 다운로드 후 1단계 스크립트 재실행 불필요 (BEST_MATCH가 이미 출력됨)

**스크립트 자동 다운로드 실패 시**: `/browse` 스킬로 수동 진행 후 curl 사용
```bash
curl -L "https://..." -o "/mnt/c/Oddments_Repository/교회/주일 예배자료/5. 찬양곡ppt/곡제목.ppt"
```

**3단계. 티스토리에도 없으면 사용자에게 알림 후 대기**

```
"[곡 제목] 파일을 티스토리에서도 찾지 못했습니다.
파일을 직접 아래 폴더에 저장해주세요:
/mnt/c/Oddments_Repository/교회/주일 예배자료/5. 찬양곡ppt/
저장 완료 후 알려주시면 계속 진행하겠습니다."
```

사용자가 완료 알림을 주면 → 1단계 스크립트 재실행 후 진행

### 매칭 결과 확인

작업 전 아래처럼 표로 매칭을 점검한다. 특히 준비찬양이 `layout=unknown`에서 나온 경우, 사용자/주보에서 확인한 순서와 일치하는지 반드시 확인한다:

```
섹션      주보 내용    매칭 파일                  슬라이드 수
준비찬양 1  꽃들도      이곳에 생명샘 솟아나...    8장
준비찬양 2  일어나 걸어라 나의 등 뒤에서...        9장
교독문    129번        교독문_129.ppt             4장
찬양 1    150장        새찬송가_150장.ppt         16장
찬양 2    147장        새찬송가_147장.ppt         12장
```

수정 사항 있으면 반영 후 진행한다.

## Step 5 – PPT 섹션 교체

`scripts/ppt_assembler.py` 를 사용해 교체를 수행한다:

```bash
python3 ~/.claude/skills/church-worship-ppt/scripts/ppt_section_replacer.py \
  --replace \
  --target "/mnt/c/.../YYMMDD주일.pptx" \
  --section "준비찬양 1" --source "찬양A.ppt" --source "찬양B.ppt" \
  --section "준비찬양 2" --source "찬양C.ppt" --source "찬양D.ppt" \
  --section "준비찬양 3" --source "찬양E.ppt" --source "찬양F.ppt" \
  --section "교독문"    --source "교독문_129.ppt" \
  --section "찬양 1"    --source "새찬송가_150장.ppt" \
  --section "찬양 2"    --source "새찬송가_147장.ppt"
```

- 한 섹션에 `--source`를 여러 개 지정하면 슬라이드가 순서대로 이어붙여 삽입된다.
- HWPX 한 페이지의 왼쪽 컬럼 이미지들 → `준비찬양 1`, 오른쪽 컬럼 이미지들 → `준비찬양 2` 순으로 매핑한다.
- HWP 추출 결과가 `layout=unknown`이면 추출 순서대로 `준비찬양 1~4`에 넣지 말고, 사용자/주보에서 확정한 곡 순서대로 `--section` / `--source`를 지정한다.
- 준비찬양이 없는 주는 `--section "준비찬양 *"` 항목을 생략한다.

스크립트 내부 동작:
1. `.ppt` 파일은 LibreOffice로 임시 `.pptx`로 변환 (`libreoffice --headless --convert-to pptx`)
2. 대상 PPT에서 `p14:sectionLst` XML로 섹션 경계(슬라이드 ID 목록) 파악
3. 해당 섹션의 기존 슬라이드 전체 제거
4. 소스 파일의 슬라이드를 동일 위치에 삽입
5. 섹션 XML 업데이트 (새 슬라이드 ID로 교체)
6. 저장

## 참고 사항

- `tamplate.pptx` 원본은 절대 수정하지 않는다
- `.ppt` 변환 시 LibreOffice 필요 (`sudo apt-get install libreoffice`)
- 자료 파일을 못 찾으면 해당 섹션은 건너뛰고 사용자에게 알린다
- 섹션명은 PPT 파일 내 `p14:sectionLst` 기준이며, 현재 섹션명: `교독문`, `찬양 1`, `찬양 2`
